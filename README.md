# SkyRun 2026 kit checklist

An unofficial, phone-friendly compulsory kit checklist for SkyRun Zimbabwe 2026, with a race picker.

Not affiliated with SkyRun. Always check the official rules and kit list at https://www.skyrunzim.com/ and the race guide.

Ticks are saved only in your own browser. Nothing is sent anywhere.

## Files

- `index.html`: the whole page (styles and script inline, no build step)
- `icon.svg`, `apple-touch-icon.png`: site icons
- `og.png`: link-preview image for WhatsApp and other apps
- `_headers`: security headers applied by Cloudflare Pages

Hosted on Cloudflare Pages straight from this repo: push to `main` and it redeploys.
