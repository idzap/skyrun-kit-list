# SkyRun 2026 kit checklist

**Live:** https://skyrun-kit-list.pages.dev

An unofficial, phone-friendly compulsory kit checklist for SkyRun Zimbabwe 2026. Pick your race, tick items off as you pack, and find the SkyRun App install steps and emergency numbers in one place.

Not affiliated with SkyRun Zimbabwe. The checklist follows the kit table in the 2026 Event Guide, and notes where the kit list on https://www.skyrunzim.com/rules-and-kit differs. The race director has the final word at kit inspection.

Ticks are saved only in your own browser. Nothing is sent anywhere.

## Files

- `index.html`: the whole page, with styles and script inline and no build step
- `icon.svg`, `apple-touch-icon.png`: site icons
- `og.png`: link-preview image for WhatsApp and other apps
- `_headers`: security headers applied by Cloudflare Pages

## Publishing

Hosted on Cloudflare Pages straight from this repo. Every push to `main` redeploys the site within about a minute.
